# 跨地研学监护协调站

本服务用于学生分组、带队交接、活动同意和离线点名。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：项目批次、学生、监护关系、分组行程、照护交接、活动同意、点名、紧急解封。

换组不能产生无人负责或双重负责；离线点名不能倒退人工确认；紧急资料限时解封；未点名按期限升级。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/student_custody.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
